## Things I've shipped

| Project | What it does | Built with |
| --- | --- | --- |
| [**splitwise**](https://github.com/Tamlica/splitwise) | Paid for the group food order? Drop in the Shopee screenshot and it works out who owes what, vouchers and fees included. The OCR runs in the browser, so the screenshot never leaves your device. | TypeScript, Tesseract.js, Supabase |
| [**makanmap**](https://github.com/Tamlica/makanmap) | A food journal that lives on a map: where you ate, where you want to eat, and where you will never eat again. With photos, half-star ratings and prices in rupiah. | TypeScript, MapLibre GL, Supabase |
| [**antijudolinator**](https://github.com/Tamlica/antijudolinator) | An Indonesian-language filter for livestream donations. It spots online-gambling promos hiding behind leetspeak and lookalike letters, keeps them off the stream overlay, and learns a new disguise every time someone confirms one. | Python, FastAPI, Docker |
| [**NeoShopper**](https://github.com/Tamlica/NeoShopper) | Shopping lists with a loud Neo Brutalism look. Works offline, on iOS and Android. | Expo, React Native, TypeScript |
| [**cooking-puzzles-mod**](https://github.com/Tamlica/cooking-puzzles-mod) | A Claude Code mod: Sudoku, an Indonesian crossword written by Claude, or Nokia-style Snake while Claude does the work. | TypeScript, Claude Code plugins |
| [**Steam-Shop-Discord-Bot**](https://github.com/Tamlica/Steam-Shop-Discord-Bot) | A daily digest of the best Steam sales, posted to Discord. No server, costs nothing to run. | JavaScript, GitHub Actions |
| [**telegram-away-bot**](https://github.com/Tamlica/telegram-away-bot) | Answers your Telegram messages when you're off the clock, so you don't have to. | Python, Telethon, Docker |

**Also built:** a YouTube-to-article generator (FastAPI, n8n, AssemblyAI, OpenAI) and a collaborative trip budget manager with multi-currency expenses (React, Supabase).
